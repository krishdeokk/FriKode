PRIVACY & TRUST BOUNDARIES

Security engineered from the ground up

Whether air-gapped on local Wi-Fi or connected over global remote tunnels, your files and keys remain under your sovereign control.

🛡️

Canonical Workspace Jail

Every file read, write, or delete request resolves canonical paths using os.path.realpath. Attempts to traverse outside the workspace root (e.g. ../../etc/passwd or ~/.ssh) are strictly denied with an HTTP 403 Forbidden error.

Enforced via path.commonpath
🔑

Isolated SSH Tunnel Keys

Public remote tunnels generate dedicated Ed25519 keys stored securely in ~/.frikode_keys/ with restricted 0600 file permissions, never touching or compromising your personal SSH keys.

Automated Ed25519 Isolation
💻

Host File Sovereignty

The host machine maintains total authority over the project filesystem. Terminating the session immediately severs tunnel relays, invalidates peer tokens, and closes all active WebSocket sync channels.

Instant Session Revocation
📡

Air-Gapped Capable & Zero Telemetry

In local Wi-Fi mode, FriKode operates 100% offline with zero cloud telemetry, no analytics beacons, and no account tracking. Packets stay strictly inside your physical room.

100% Offline Capable
