# Welcome to FriKode

FriKode is a collaborative code editor for developers on the same Wi-Fi or collaborating remotely across different networks.

## Key Features
- **Local & Remote Collaboration**: Work locally on the same Wi-Fi or generate a 1-click worldwide link for teammates on different networks.
- **In-Browser Multi-Language Compiler**: Run Python, C, JavaScript, and more directly inside the integrated console (`Cmd/Ctrl+Enter`).
- **Real-time CRDT Sync**: Edit files simultaneously with teammates without collisions.
- **Collaborator Presence**: See peer cursors, selections, and active files in real time.
- **Zero Cloud Accounts**: Runs 100% directly from the host machine with zero account registrations.

## Quick Start
1. Invite teammates using the Wi-Fi link or the Remote Access button in the top bar.
2. Click any file in the explorer to start collaborating live!
3. Press `Cmd/Ctrl+Enter` to run code and see output in the integrated console.
