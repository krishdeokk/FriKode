# Welcome to FriKode

FriKode is a local-network collaborative code editor for developers on the same Wi-Fi.

## Key Features
- **Zero Cloud**: Runs 100% locally on your machine.
- **Real-time CRDT Sync**: Edit files simultaneously with teammates without collisions.
- **Collaborator Presence**: See peer cursors, selections, and active files in real time.
- **Local Network Sharing**: Connect instantly using your Wi-Fi address or session code.

## Quick Start
1. Invite teammates using the Wi-Fi link in the top bar.
2. Click any file in the explorer to start collaborating live!
